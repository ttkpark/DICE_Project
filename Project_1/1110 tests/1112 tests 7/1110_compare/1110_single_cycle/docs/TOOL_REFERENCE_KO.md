# 도구 명령 참고

- 서버 wrapper 실행 방식은 기존 수업 배포 SYNOPSYS_QUEUE_README의 vcs_queue / dc_shell_queue 기준.
- Synopsys Power Compiler Quick Reference, C-2009.06. read_saif의 instance_name·auto_map_names, report_power 명령. 원저작자 Synopsys, 대학 보관 사본: https://users.ece.utexas.edu/~mcdermot/vlsi1/VLSI2_SP_2017/synopsys/doc/POWER_Compiler/pwr_cmplr_qref.pdf
- Synopsys Power Compiler User Guide, U-2022.12-SP3. saif_map의 RTL-to-gate 이름 매핑과 activity 재주석 흐름. 원저작자 Synopsys, 공개 보관 사본: https://iccircle.com/static/upload/img20240918122431.pdf

서버 설치 버전의 help read_saif / help saif_map / help report_power로 지원 옵션 확인. 상용 도구 명령의 로컬 Tcl 구문 검사는 해당 라이선스 도구에서의 실행 검증을 대신하지 않음.
