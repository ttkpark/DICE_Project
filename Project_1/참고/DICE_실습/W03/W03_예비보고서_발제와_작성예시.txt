EE362 3주차 예비보고서
조합회로 기초 조사와 내 보드에 맞는 FPGA 예제 실행

제출 형식: 수업 전 A4 1쪽. 기초 개념, 보드·예제 선택 근거, 본인의 실행 사진과 결과표 포함.

1. 조합회로와 Verilog 기초 조사
   - 2:1 MUX의 S=0, S=1 선택표 작성.
   - always @(*)의 의미와 if/else·case의 표현 방법 확인.
   - else 또는 default의 출력 대입을 빠뜨릴 때 생기는 문제 정리.

2. 보드 확인 후 예제 하나 선택
   - 본인 보드의 모델명과 FPGA 칩 전체 품번 확인. 이름이 비슷하다는 이유로 임의 선택하지 않음.
   - 원래 DE2 / EP2C35F672C6: fpga_demo/DE2/W03_HEX_DEMO_DE2.qpf 선택.
   - DE2-115 / EP4CE115F29C7: fpga_demo/DE2_115/W03_HEX_DEMO_DE2_115.qpf 선택.
   - DE2-115용은 JP7 기본 2.5V(핀 5–6 연결) 조건. 설정이 다르거나 불확실하면 전원·점퍼를 임의로 조작하지 말고 조교 확인.
   - 두 버전 모두 완성 코드이며 한 가지만 실행. 다른 모델·품번은 그대로 실행하지 않고 대응 예제 또는 설정 수정에 관해 조교 확인.

3. 선택한 예제 실행
   - 선택한 보드 폴더 전체를 복사한 뒤 그 안의 README_KO.md 순서대로 진행.
   - 해당 프로젝트에서 새로 컴파일한 SOF만 사용. 다른 보드용 또는 설정 변경 전 SOF 재사용 금지.
   - 입력 0000, 0001, 1000, 1001, 1010을 차례로 적용하여 0, 1, 8, 9, 전체 소등 확인.
   - 공식 매뉴얼의 장치·핀·I/O 설정 대조. 강의 Appendix C의 화면과 핀 값은 원래 DE2 예시이며 DE2-115에는 선택 폴더의 설정 적용.

보고서에 넣을 기록
   - 보드 모델·FPGA 품번, 선택한 프로젝트, DE2-115 사용 시 JP7 확인 결과.
   - Programmer 완료 화면과 본인 보드의 숫자 8 사진, 다섯 입력의 실제 관찰 결과표.
   - active-low의 의미 한 문장과 오류가 있었다면 원인·수정 사항.

짧은 작성 예시
   조합회로는 현재 입력으로 출력이 정해지는 회로. MUX는 S=0에서 A, S=1에서 B를 선택. always @(*)는 블록에서 읽는 입력 변화에 따른 재계산을 위한 표현. 모든 분기에 출력 대입이 필요하며, 대입 누락 시 이전 값 유지 가능.
   보드·프로젝트명과 관찰표는 본인 실행 결과로 작성. 예상값이나 강의 캡처를 본인의 결과로 사용하지 않음.

보드 사용이나 설정 확인이 어려운 경우 수업 전에 조교에게 문의. 확인 전에는 시뮬레이션까지만 진행하고 미실행 사유 기록. 시뮬레이션 PASS를 보드 실행 완료로 기재하지 않음.
두 자리 가산기 W03_TOP의 연결과 조교 Checkpoint는 별도 과제. 이번 보드별 분리는 예비보고서용 한 자리 예제에만 적용.
