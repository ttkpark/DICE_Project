# 먼저 보드 확인, 그다음 폴더 선택

1. 보드 모델명과 FPGA 칩의 전체 부품명 확인.
2. 원래 DE2 / EP2C35F672C6이면 `DE2`, DE2-115 / EP4CE115F29C7이면 `DE2_115` 선택.
3. 해당 모델의 공식 설명서와 폴더 안 `README_KO.md` 확인.
4. DE2-115는 JP7 기본 설정(5–6 연결, 2.5V) 확인. 기본값이 아니거나 불확실하면 조교에게 문의. 전원이 켜졌거나 확장 보드가 연결된 상태에서 임의 변경 금지.
5. 프로젝트의 장치·핀·I/O 확인. DE2의 3.3-V LVTTL과 DE2-115 예제의 2.5 V를 혼용하지 않음.
6. 선택한 프로젝트를 새로 컴파일하고 그 폴더의 새 SOF만 프로그램. 다른 보드나 이전 설정의 SOF 재사용 금지.
7. 입력 0·1·8·9·10의 실제 표시 확인. 목표는 0·1·8·9·소등.

| 보드 | 열 프로젝트 | 프로그램할 파일 |
|---|---|---|
| 원래 DE2 | DE2/W03_HEX_DEMO_DE2.qpf | DE2/output_files/W03_HEX_DEMO_DE2.sof |
| DE2-115 | DE2_115/W03_HEX_DEMO_DE2_115.qpf | DE2_115/output_files/W03_HEX_DEMO_DE2_115.sof |

다른 모델·다른 FPGA 부품·불확실한 설정은 자동 지원하지 않습니다. 장치 이름만 바꾸고 기존 핀·전압을 남기지 않습니다. Start 전에 조교에게 확인받습니다.

보고서에는 보드·FPGA 이름, 선택한 프로젝트, 수정한 설정(없으면 없음), Programmer 완료 화면, 숫자 8 보드 사진, 다섯 입력의 관찰표를 포함합니다. 미실행 결과를 만들지 말고 필요한 실습 시간·장소를 조교에게 문의합니다. 전체 발제는 상위 W03 폴더의 `W03_예비보고서_발제와_작성예시.txt`를 따릅니다.
